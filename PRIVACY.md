# Privacy

Maglucen Stardew Valley Companion is designed to run locally.

- Save files and generated farm data remain on the user's computer.
- The local dashboard is bound to the loopback interface and protected so it can only be opened by the desktop application.
- The application does not require an account.
- Update checks contact this GitHub repository to determine whether a newer public release exists.
- Diagnostic information is stored locally. It is only shared when the user chooses to include it in a support report.

This document will be updated if a future version introduces any network service beyond release checks.
